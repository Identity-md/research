## Facts (read directly from the sources)
- Each job page shows the scoring prompt, a headline answer, and a list of agent answers. By default the list shows 5 answers plus an "N more" fold; the `?panel=all` page has all of them. For every job, the number of rows I parsed equals the page's "X of N" total.
- On the **NightShiftImd** and **Imdirectorb** pages, the explorer shows scores as token amounts, e.g. `0.000000000000000074 IMD`. The page labels the raw value as `74 uint256, 18 decimals`. I converted these to integers by multiplying by 10^18, so `0.000000000000000074 IMD` = 74. Every converted value is a whole number from 0 to 100.
- Excluded: 2 rows in total, both on Imdirectorb, and both marked **not read** by the explorer: agent #1501 ("Too big: expected string to have <=512 characters") and agent #1708 ("answer is not JSON"). No other job has an error row. Every other row has an integer score; most are marked "differed".
- All 15 panels failed to reach the required agreement: "within 5% · 70 needed", and at most 52 of ~95 agreed (SeerOnIMD).

## Inferences
- The average is the arithmetic mean of every valid agent score, with every agent weighted equally, rounded half-up to 2 decimals. The `Sum / count` column gives the exact fraction so anyone can re-check it.
- The headline "Answer" at the top of each page is **not** the panel mean (for example, swornbyswarm shows 77, but the mean is 70.18). It seems to be a single agent's answer, perhaps the job's first or reference responder. It is shown only for comparison and was not used in the averages.
- Reading the 10^-18 IMD display as the integer score is based on the page's own label ("uint256, 18 decimals") and on the prompt asking for an integer from 0 to 100.

## Uncertainty and open questions
- These are snapshots from 2026-10-28. If a job later receives more answers, or the explorer changes its pages, the numbers could change.
- The explorer page is the only source. I did not cross-check the agents' answers against the onchain records.
- The request does not say whether "differed" answers (outliers from the panel consensus) should count. I included them, because the only exclusion requested was for errors such as not_read.
- I did not check whether any one agent's score is reasonable. These averages describe what the panel said, not how good the projects are.
