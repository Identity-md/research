## Method and evidence quality

Public web searches used the project spellings “Identity MD”, “IdentityMD”, “Identity.md” and the cashtag “$IMD”, plus account-specific searches. Searches surfaced Sotwe, TwStalker and Zamantika timeline reproductions. Relevant entries required an explicit project spelling, cashtag, or unmistakable project context such as imd.fun or imd_bot. Unrelated uses of IMD were excluded. A post mentioning the project and token counts once, rather than once for each keyword. Long posts count once; unseen thread parts do not count.

The table documents a deliberately small, manually distinguishable set of entries for each account. It is not an exhaustive count even within each profile. Evidence was read from search excerpts and, where successful, opened mirror pages. All source links were consulted on the research date; linked pages can subsequently change. Direct opens of x.com/surfcoderepeat and x.com/LastToSign failed, and four targeted site:x.com searches returned no results. Some mirror opens also failed, so their entries rely on indexed excerpts. No authenticated X search, API export or independent archive was obtained.

**Observed facts:** the consulted reproductions attribute the listed entries to the listed handles. Relative ages and the displayed Sep 5 label are mirror metadata. Some search and open responses for the same URL showed different snapshots, so relative ages must not be converted into exact calendar dates or used as a consistent measurement window.

**Inference:** repeated authored mentions make these useful candidates for a monitoring list. Mirror's seven selected entries, displayed within roughly a day in one snapshot, give it the strongest visible frequency signal in this sample. Selection and indexing bias prevent concluding that it is the most frequent account across X.

**Uncertainty:** third-party reproductions can be stale, incomplete, incorrectly attributed or missing deleted posts and replies. Account identity, exact publication times, comprehensive coverage and current activity were not independently verified on X. Search visibility, engagement and follower counts do not measure posting frequency. No statistical confidence interval is justified.

**Unanswered question:** who posted the most in a common recent period, such as 1–30 September 2026? Resolving that requires a dated X dataset containing post IDs, author handles, UTC timestamps and post types. Deduplicate by post ID, verify token context, then rank authored mentions separately from reposts over that same window. Until then, use this shortlist as discovery evidence rather than an exact leaderboard.
