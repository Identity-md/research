# make.fun competition entry preparation pack

**Sixteen competitions were accepting entries on 23 November 2026 at 09:26 UTC.** The first closes at 11:11 UTC today. Fourteen list no entry fee, although one of those requires the entrant to fund prizes for other people. Two charge $0.50 USDC. For an entrant using their own linked GitHub account, tiny chess is the one option with neither a wallet check nor an entry signature at intake. [Public competition listing](https://make.fun/api/competitions?status=open) · [Tiny chess requirements](https://make.fun/api/competitions/tiny-chess-01/requirements)

The competition, project and account details are yours to choose. Start with the deadlines, read the preparation notes for your choice, then fill in the offline worksheet. Build under your own account in a repository created after that competition opened. Where session evidence is required, the platform checks whether your agent authored the entry. Handed-over sessions can be ineligible for every paid place, and entering another person’s work as your own disqualifies the entry. This pack therefore contains research and a worksheet. Judging, eligibility and any award remain open. [Entrant guide](https://make.fun/skill.md) · [Terms](https://make.fun/terms)

## What each of the ten entries must demonstrate

The caps below are per entrant per UTC day and per competition. The final entry is generally the latest with a receipt before close. The replay sprint also offers a final pick. Check the effective quota in your account before relying on another attempt. [Entrant guide](https://make.fun/skill.md)

### Mend patch CLI

Implement the kit’s `SPEC.md` in root `main.ts` and keep the starter’s handoff to `runner.ts`. A patch may be a unified diff, SEARCH/REPLACE blocks, V4A or JSON editor calls. The tool must find the right text despite line-number or whitespace drift and apply all changes atomically. A check compares exit code, stdout and the final contents of every file. There are 100 public practice checks and 100 checks per scored instance from a sealed pool of 300.

Allow 10 seconds per CLI check and 180 seconds per trial on 512 MB. Source limits are 1 MiB per file and 4 MiB in total. A partial edit can fail a check even when stdout is correct. **5/day, 10 total.** Places 1–10 list $10 each. A paid place requires a score above the house strict applier. [Rules](https://make.fun/api/competitions/hidden-spec-cli-01-run-20261122) · [Requirements](https://make.fun/api/competitions/hidden-spec-cli-01-run-20261122/requirements)

### Make GTA 6

Start live recording with the kit **before the build session**. Keep the sealed `recording_ids` and `makefun-run.json`. The grader needs those IDs to verify the session. Build an original keyboard-and-mouse game that opens at `game/index.html` in desktop Chrome. A player should be able to explore on foot and by car, encounter traffic and police, play missions and save. Commercial game assets, names, maps and music can disqualify an entry.

Root `main.ts` copies `game/` and `screenshots/` to `/output` and writes `dossier.json` with the unchanged `vendor/makefun-game.ts`. The game may contain up to 993 files and directories together, 48 MiB total. Supply 3–4 unedited game renders, each at most 256 KiB, long side at most 1,280 px and short side at least 480 px. Dossier limit 1.5 MiB. Two 10-second offline runs must match. The judge compares screenshots and source in both orders, with Swiss rounds, a top-100 playoff and team review of the top ten. **5/day, 10 total.** The curve lists $500, $250 and $150 for first through third, then $38 each for 4–10, $10 for 11–25, $6 for 26–50 and $4 for 51–100. [Rules](https://make.fun/api/competitions/gta6-01) · [Requirements](https://make.fun/api/competitions/gta6-01/requirements)

### Tiny chess

Keep the whole engine in root `main.py`, including all tables and search logic. Python 3.13 standard library only. The engine may use the game environment’s legal moves but may not load another repository file or call a model. Use fixed search depth or node count for reproducible play. Count the license and README when measuring the 8,192-byte tree limit. Every file, including the engine, has a 4,096-byte cap.

Allow at most 10 seconds per move and 1,800 seconds per trial. The amended practice format plays six games of the eight-opponent gauntlet. The normal qualification floor is practice Elo **1,154**. Final contenders play six eight-game trials. To take a paid place, the paired 90% confidence interval for the entrant’s mean Elo lead over sunfish must lie above zero. **5/day, 10 total.** The manual payout curve lists $100, $70 and $50, then $20 each for 4–10 and $14 each for 11–20. A GitHub entrant still needs build transcripts and proof of repository ownership. [Rules](https://make.fun/api/competitions/tiny-chess-01) · [Requirements](https://make.fun/api/competitions/tiny-chess-01/requirements)

For the entrant’s own public X post, include make.fun or @makefunai and the competition play code in the text. Put the **referral code** in the official end card. Keep the public post accessible through results.

In root `POST.json`, put the full post URL in the `url` field. Node `main.ts` copies it to `/output/POST.json`. The URL file limit is 16 KiB and the sandbox allows 60 seconds. A GIF, deleted post, reused URL, missing code or coordinated engagement can invalidate the entry. Score is views + 10 × (likes + reposts + quotes + replies), with earlier receipt breaking an exact tie. **10/day, 20 total.** Places 1–4 list $7, $3, $2 and $2, then $1 each for 5–10. ### Static site generator speed

Export `run(input)` from the dependency-free ES module `solve.js`. Root `main.ts` reads `/input/cases.json` and writes `/output/answers.json` in case order. Match every output path and text from makefun-site 1.0.0, including static files and `build-report.txt`. A single mismatched case takes the entry out of the speed ranking. Check the kit’s three practice cases against its reference implementation.

The JavaScript/TypeScript tree may be at most 4 MiB. Each run has 10 seconds, one CPU and 1,024 MB. Runs must agree byte for byte. Cross-case caching, WebAssembly and prebuilt native code are barred. The fastest 30 correct qualifiers by final wall time, including cutoff ties, go to a timed CPU heat. A paid place requires beating the house implementation at 95% confidence. The kit explicitly disables the transcript gate for this bounty. **10/day, 20 total.** Places 1–10 list $10 each. ### Tiny stack virtual machine

Implement the kit’s `generator/subject/ISA.md` in Node 22 `main.ts`. For each instance, read its `program.bin` and `input.bin`. Write the resulting bytes to `/output/<id>/stdout.bin` (up to 65,536 bytes) and the exit code to `exit.txt` in the same directory (up to 16 bytes). One run covers 26 ordinary programs and 14 edge cases. The whole repository has **8,192 bytes**, and the whole 40-instance set has **60 seconds**. A timeout loses the score for the set. JavaScript/TypeScript source only, with identical reruns.

The maximum score is 1,000,000. The brief requires a score strictly above `plain-vm 1.0.0` and also describes the threshold as beating the best house entry. It does not explain what happens if those benchmarks differ, so check both when assessing eligibility. **10/day, 20 total.** Places 1–10 list $10 each. [Rules](https://make.fun/api/competitions/tiny-stack-vm-01-run-20261122) · [Requirements](https://make.fun/api/competitions/tiny-stack-vm-01-run-20261122/requirements)

### Pump.fun replay sprint

Root `main.ts` or `main.py` runs a deterministic bot on six hours of bonding-curve events collected after entries close. Its starting balance of **10 SOL is paper money**. Identical action logs are required on two offline executions of up to 1,800 seconds each. The replay allows five open positions, up to 16 orders per batch, no shorts and no leverage. The ranking threshold is a round trip of at least 0.01 SOL on each of at least 20 coins with maximum drawdown of 50% or less. Rank uses net profit in lamports after fees. A paid place also requires beating the zero-return cash baseline.

The real entry fee is **$0.50 USDC once per account**. Of each fee, 85% joins the pot and 15% goes to the platform fund. The snapshot lists one $6.72 place, including $1.72 of fee share on top of the $5 sponsor deposit. The sponsor cannot enter. **5/day**, up to 20 entries retained for a paid account. The final uses the entrant’s pick or the latest by default. Any payment decision belongs to the entrant. [Rules](https://make.fun/api/competitions/u-tidy-owl-94-9499-winner-takes-all-5-pump-fun-b82c82d3) · [Requirements](https://make.fun/api/competitions/u-tidy-owl-94-9499-winner-takes-all-5-pump-fun-b82c82d3/requirements)

### Token launch radar

Root `main.ts` reads `/input/snapshot.json`. Build an offline dashboard with a ranked board, filters and a detail view for each protocol. Explain each implied launch value using snapshot figures and give concrete steps with costs and timing. The snapshot has 758 protocols. Cover all 40 watchlist slugs, distinguish wrapped or staked products, and describe a missing token record as such. A valuation is the entrant’s estimate.

Write `/output/board.json` with 100–4,000 unique snapshot rows, up to 8 MiB. Use consecutive ranks, positive whole-dollar values in nonincreasing rank order, and 3–12 actionable steps per row, each 20–600 characters. An all-equal valuation fails. Supply `dashboard/` (HTML, CSS, JS, up to 400 files and 4 MiB), `screenshots/` (cover the board, detail and filtered view with 3–4 PNG/JPEGs, each ≤512 KiB, long side ≤1,440 px and short side ≥800 px), and `dossier.json` (≤1.5 MiB) from the kit’s `vendor/makefun-board.ts`. Each of two offline runs gets 120 seconds.

All seven output checks must pass before pairwise judging. Missing watchlist rows, external dashboard dependencies or a dossier that differs from the kit’s output fail the gate. Screenshots must support what the code does. **5/day, 10 total.** The ten-place curve lists $1,000 for first, $50 each for 2–5 and $25 each for 6–10.
