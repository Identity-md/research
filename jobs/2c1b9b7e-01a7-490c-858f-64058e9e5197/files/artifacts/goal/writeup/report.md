## What a proof must show

Let `I` be an incidence relation between `N` points and `N` lines with no 4-cycle. The target function is true precisely when the active inputs contain an incident point and line. Given a `Monotone2` circuit `C` that satisfies `ReadsBack (N+N)` and computes this function, the step asks for a circuit `D` with the same properties and `D.size ≤ C.size`. Every AND gate of `D` must be false on each input consisting of a single point or line (the **singleton clause**) and on each input consisting of a point and a non-incident line (the **pair clause**). When `I` is empty, the gate list `[]` with output index `N+N` computes false and satisfies both clauses. [Angle 1](#angle-1) · [Angle 2](#angle-2)

The size requirement is equivalent to the existence of **one** minimum-size circuit satisfying both clauses for each such function with a circuit. Apply the step to a minimum-size circuit to get one direction. For the converse, a clean minimum-size witness already meets the size bound for any admissible `C`. Thus a counterexample would need to exclude *every* clean witness at the minimum size. Angle 1 also reports that `L_meta_3447` derives `|I| ≤ 5*C.size + 1` under the two cleanliness hypotheses. L-meta-3451 would supply those hypotheses without increasing size. [Angle 1](#angle-1) · [Angle 4](#angle-4)

## Where the size argument stops

A clean circuit is easy to construct for a nonempty relation. Assign each edge to one endpoint in a minimum vertex cover of size `τ`. For a vertex assigned `d > 0` edges, OR its assigned neighbors with `d−1` gates and AND the result with the vertex. OR together the resulting terms. This computes the incidence function using at most `|E| + τ − 1` gates. Each AND requires an incident pair. Angle 4 reports equality of the minimum size with this bound on all 79 decided classes. A matching lower bound for arbitrary 4-cycle-free graphs would prove the step, but the record establishes it only in those finite cases. [Angle 4](#angle-4)

The alternative is to clean a circuit while retaining its size bound. Angle 2 identifies the obstruction to a local saving. Hoisting a shared input out of `(x ∨ u) ∧ (x ∨ v)` can cost a gate when other gates still read both ORs. For the pair clause, Angle 2 gives an example where a gate can be true on a non-edge yet the corresponding clean expression uses the same number of gates above the two existing ORs. Correcting a value on an input where the output is already false does not by itself supply a gate-count argument. The four records leave open how to construct a clean witness for arbitrary `N` within the original budget. [Angle 1](#angle-1) · [Angle 2](#angle-2) · [Angle 3](#angle-3) · [Angle 4](#angle-4)
