## 4. Results by problem: discoveries, counterexamples, dead ends
**cp4.** Upper bound 109 in two forms: an explicit derivation of 45 axioms + 44 additions + 20 unary steps (cp4-mp), and a reflective Bool checker (cp4-la), which cp4-la2 extended to enforce strictly backward references and count each line once. Lower-bound accounting: all 45 clause axioms are forced (cp4-ct); for a trimmed derivation DAG, N >= 101 + 2B + R, where B counts Boolean-axiom leaves and R clause-leaf occurrences beyond 45 (cp4-ct2, four files, both reviews pass). A 108-line run would therefore need 2B + R <= 7. cp4-mp2 proved a divisibility obstruction for uniform partial-star sums, which closes the "pool, then round once" shortcut. Reviewer finding (cp4-v1): a triangle cut excludes the all-half point in one division. Dead ends: pooled rounding; dropping divisions; a fixed-prefix SMT search for 108 timed out without an answer (cp4-cd2); the read-once minima 19/52/109 (cp4-cd) hold in a restricted model only. Open: show every equality case of the cp4-ct2 charge meets its hypotheses.

**cp5.** The 196-line certificate is 81 axioms + 80 additions + 15 multiplications + 20 divisions (cp5-cd symmetric witness, cp5-la trace). The chain family obeys f(n) + n = n^3 + 3n^2 + 1 for n >= 2. New lemmas: a weighted partial-star partition criterion (cp5-mp2) and cross-hole rounding/excess lemmas with a shared-window construction of 197 lines, one worse than the baseline (cp5-cd2). No local multiply/divide fusion shortens the 196 trace (cp5-la2), but cp5-v1 found that the exploratory fusion script accepts a negative multiplier and crashes on a legal zero multiplier, so that negative result is weak. The general restriction lemma "L - 15" (cp5-ct2) does not compile and is unproved. The 196 certificate itself has an author-side `ACCEPTED` but no independent official pass: cp5-v2 ran it against a 197 statement file by mistake.

**res.** Upper bound 157: a Hall-type DAG of 45 axioms + 112 resolvents, width 7, every line used (res-cd). res-v2 replayed it with its own interpreter: 157 distinct lines, 10 shared derived lines, tree-like unfolding 377. Lower bounds: every refutation contains all 45 axioms (res-ct2); routing adjacent critical assignments through one DAG with parent choices fixed first charges 45 + 40 + 16 distinct lines, a floor of 101, with ordered first splits (res-mp2); a wrapper over the project's existing L_pcx_162 states 110. A memoised replay checker passed; its subsumption variant fails at line 167 on an identifier absent from the pinned Mathlib (res-la2). Searches: Hall-family SAT cannot reach 150 (that family only); splicing found nothing shorter (res-cd2). Reviewer finding (res-v1): four collision labels can share one first-split line, so first-split counting alone goes no further. Open: lower bounds that survive shared parents.

**lin.** Upper bound 149: 40 axioms + 54 semantic weakenings + 55 resolutions, from the ordinary-to-parity simulation (lin-ct), turned by lin-la2 into one Lean file whose weakenings are checked by truth tables on the visible variables with kernel `decide`. lin-v2 replayed it over all 1,024 assignments. Inside two finite clause libraries (169 and 449 clauses) the minimum is 149, and a one-clause variant of the trace exists (lin-cd2; restricted). Full pair projections cost 110 lines before at least 9 finishing lines, so any proof of <= 111 lines must interleave; lin-mp2 gave 12- and 19-line local derivations for that. Corrections: BPHP 3 1 has two holes and six clauses with both signs, not three all-negative clauses as lin-mp wrote; the affine two-source obstruction (lin-ct2) fails to compile at line 113 (XOR/equality precedence). Observation (lin-v2): rank rises from 2 to 5 across one weakening (line 11), so rank is no monotone invariant.

**plane.** Upper bound 64: a balanced circuit (plane-la; the same bytes from plane-la2) and a left-chain variant (plane-mp; no verdict, its check timed out). The promise is 52 positive pairs and 236 promised false rows. Counterexamples: a 63-gate edit that passes all 24 cyclic representatives fails the incident pair (10,1), so symmetric spot tests are unsound for asymmetric candidates (plane-v1); a 69-gate circuit that is right on the promise accepts the off-promise input P={0,1,2}, W={3,7,8} (plane-cd2); removing a guard gives a concrete failing input (plane-ct). Lemmas: relabelling/equivariance and a stabiliser lemma for sound symmetry cuts (plane-ct2); a local-window UNSAT certificate and a care-set lemma (plane-cd2); a 39-OR minimum inside a restricted support model (plane-cd). OR-only sharing, single deletions, small rewires and masked products (plane-mp2) do not reach 63, and nothing excludes 63.

## 9. Extraction
The block below is Base85 (Python `base64.b85encode`) of one xz stream, 31,828 bytes, SHA-256 `1d7e8f5d3688dcf2307f0996c7ccaaf6e29e88945c8776c9a113261f61e117be`. Decompressed it is 234,873 bytes: each file of section 8 in table order, each followed at once by its statement file. Save this report as `report.md` and run, with Python 3 only:

```python
import re,base64,lzma,hashlib,os
t=open('report.md',encoding='utf-8').read()
z=base64.b85decode(''.join(re.search(r'```b85\n(.*?)\n```\n',t,re.S)[1].split()))
assert hashlib.sha256(z).hexdigest()=='1d7e8f5d3688dcf2307f0996c7ccaaf6e29e88945c8776c9a113261f61e117be'
d=lzma.decompress(z);o=0
for f,n,h,s in re.findall(r'^\|`(\S+)`\|(\d+)\|(\w{8})\|(\d+)\|',t,re.M):
    f='proofs/'+f+'.lean';os.makedirs(os.path.dirname(f),exist_ok=True)
    for p,k in((f,int(n)),(f+'.statement.txt',int(s))):
        b=d[o:o+k];o+=k
        if p==f:assert hashlib.sha256(b).hexdigest()[:8]==h,f
        if k:open(p,'wb').write(b)
assert o==len(d);print('ok',o)
```
