It covers their selected five clients per layer; it does not claim a market-share ranking. “Newest stable” means the release selected by that research, excluding drafts and prereleases. Dates are publication dates in UTC. Links identify the underlying pages; `/latest` and branch links can change after this snapshot. Selected pages were spot-checked for this write-up; this was not a fresh audit of every source.

**Currency and release context.** Subtracting the table's publication dates from 27 October gives release ages of one to five calendar days: execution releases are dated 23 or 26 October, and consensus releases 22 or 23 October. These are very recent selected releases, but release age alone does not establish deployment or adoption. The calculation uses the publication records linked in the table. Merge-02 reports that all five consensus items checked `draft: false` and `prerelease: false`; Lighthouse's newer-looking `v8.4.0-rc.0` was excluded as a [prerelease](https://github.com/sigp/lighthouse/releases).

Much of the activity is coordinated around the Hoodi testnet schedule. Geth postpones Amsterdam and also changes snap/2 selection and DUP/SWAP interpreter dispatch; Erigon postpones the Hoodi fork and planned 200-million gas-limit increase while fixing Caplin state, cache, reorganization and validator-vote handling; Reth removes Amsterdam from Hoodi without database changes. Sources: [Geth notes](https://github.com/ethereum/go-ethereum/releases/tag/v1.17.10), [Erigon notes](https://github.com/erigontech/erigon/releases/tag/v3.8.1), [Reth notes](https://github.com/paradigmxyz/reth/releases/tag/v2.8.1).

The other execution updates emphasize security and correctness. Nethermind packages October out-of-band .NET security updates and runtime 10.0.14 without Nethermind code, database, configuration, consensus or fork-schedule changes. Besu removes eMudhra root certificates from Docker trust stores, caps `eth_getProof` at 1,024 storage keys and fixes Osaka MODEXP gas-cost saturation for large declared lengths. Sources: [Nethermind notes](https://github.com/NethermindEth/nethermind/releases/tag/2.2.2), [Besu notes](https://github.com/besu-eth/besu/releases/tag/26.10.2).

All five consensus releases unschedule Hoodi's Gloas/Glamsterdam activation. Lighthouse gives the former deadline as 26 October 2026, 17:42:48 UTC; Teku and Lodestar give epoch 132352. Upgrade urgency is client-specific: Lighthouse says mainnet users need not upgrade; Prysm says mainnet users already on v7.3.0 need not; Teku makes the update optional outside Hoodi; Nimbus rates it low-urgency outside Hoodi. Lodestar calls its update critical for all users, also refreshing Node.js after the eMudhra CA compromise and requiring Node.js 24.22.1 or newer, including an operator-managed update for source builds. Sources: [Lighthouse](https://github.com/sigp/lighthouse/releases/tag/v8.3.2), [Prysm](https://github.com/OffchainLabs/prysm/releases/tag/v7.3.1), [Teku](https://github.com/Consensys-Incorporated/teku/releases/tag/26.10.2), [Nimbus](https://github.com/status-im/nimbus-eth2/releases/tag/v26.10.2), [Lodestar](https://github.com/ChainSafe/lodestar/releases/tag/v1.50.1).

**Variety.** Counting the sourced language cells gives six main languages overall: Go, C#, Java, Rust, Nim and TypeScript. Execution spans four; consensus spans five, with a different language for each selected consensus client. The maintainer cells also show a range of teams, companies and a maintainers group, with weaker evidence for Nimbus explicitly identified. This is a comparison of implementation and attribution, not a measure of independent code, organisational control or network market share. The license cells show Apache-2.0 and MIT/Apache-2.0 choices alongside GPL/LGPL-family terms; Geth's executable/library distinction prevents reducing its licensing to one unqualified label. These comparisons derive from the linked table cells.

**Disagreements and evidence limits.** Neither merge reports a missing item; their client sets do not overlap, so they offer no independent cross-check of the same client's fields. The following qualifications remain material:

- Nethermind's [README license section](https://github.com/NethermindEth/nethermind/blob/master/README.md#license) and [file SPDX header](https://github.com/NethermindEth/nethermind/blob/master/src/Nethermind/Nethermind.Runner/Program.cs) support LGPL-3.0-only, while [GitHub repository metadata](https://api.github.com/repos/NethermindEth/nethermind) reports GPL-3.0. The table follows the project/file evidence and preserves the conflict.
- Nimbus's [repository license detector](https://api.github.com/repos/status-im/nimbus-eth2) reports `NOASSERTION`, whereas its [README](https://github.com/status-im/nimbus-eth2/blob/stable/README.md#license) explicitly offers MIT or Apache-2.0 at the user's option. The detector result is not treated as the project's license. The supplied research did not establish a maintainer statement beyond [status-im repository ownership](https://github.com/status-im/nimbus-eth2).
- Prysm's [metadata](https://api.github.com/repos/OffchainLabs/prysm/license) uses `GPL-3.0`, a [deprecated SPDX identifier](https://spdx.org/licenses/GPL-3.0.html). Its precise `-only` versus `-or-later` form was not established. Erigon likewise has only the unsuffixed `LGPL-3.0` [metadata value](https://api.github.com/repos/erigontech/erigon) in the supplied evidence. Neither suffix is guessed.
- Merge-02 had only repository-owner evidence for Lodestar's maintainer and metadata for its language/license. The spot-checked [README](https://github.com/ChainSafe/lodestar#lodestar-ethereum-consensus-implementation) explicitly attributes development to ChainSafe Systems and describes TypeScript; its [architecture section](https://github.com/ChainSafe/lodestar#architecture-overview) states Apache-2.0 for the monorepository while warning that packages have their own licenses. This strengthens, rather than contradicts, those entries.
- Merge-02 calls every consensus update a Hoodi-driven patch “not a feature release,” yet also records Nimbus feature additions. Nimbus's [release notes](https://github.com/status-im/nimbus-eth2/releases/tag/v26.10.2) support multiple payload-builder URLs and new REST endpoints, including getProposerPreferences, getStatePtc and getProposerLookahead. TOML users must change the builder URL setting to a list. Hoodi motivation and feature content coexist; the blanket description is too broad.
- Merge-02 flags Teku's `Consensys-Incorporated` repository path as unusual. Its [26.10.2 release page](https://github.com/Consensys-Incorporated/teku/releases/tag/26.10.2) was accessible during the spot check; the cited path is retained. A different repository location was not established.

Some evidence is release-pinned (notably Geth's headers, Reth's manifest and Lighthouse's README/license); other evidence is mutable repository metadata or branch documentation. License suffixes and Nimbus's explicit maintenance attribution remain unresolved as stated above. No missing precision has been supplied by inference.
